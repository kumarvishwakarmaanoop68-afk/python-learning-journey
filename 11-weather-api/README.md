# 🌤️ Python Weather API App

Day 11 of my Python learning journey.

## Project: Weather API App

A console-based Python project that fetches weather data from a public API and displays useful information for a city.

## Features

- Enter a city name
- Fetch current weather data
- Display temperature and weather condition
- Display humidity and wind speed
- Handle invalid cities
- Handle API and network errors
- Use OOP to organize the application
- Save the latest result to JSON

## API

This project uses the Open-Meteo API, which does not require an API key.

## Concepts Used

- Classes and objects
- Methods
- HTTP GET requests
- JSON
- API error handling
- File handling
- Lists and dictionaries
- User input validation

## Run

Install the requests library:

```bash
pip install requests
```

Then run:

```bash
python weather_app.py
```

## Learning Goal

Build a practical API project while improving Python OOP, JSON, requests, and error handling skills.
