# 💰 Python Expense Tracker

Day 9 of my Python learning journey.

## Project: Expense Tracker

A console-based expense tracker that stores income and expenses in a JSON file.

## Features

- Add income
- Add expense
- View all transactions
- Filter transactions by category
- Show total income
- Show total expenses
- Show current balance
- Save data in JSON
- Load data when the program starts
- Basic input validation and error handling

## Concepts Used

- Functions
- Classes and objects
- Lists and dictionaries
- JSON and file handling
- Exception handling
- Date and time
- Loops and conditions

## Run

Run `python expense_tracker.py` from this folder.

The application creates and updates `transactions.json` automatically.
