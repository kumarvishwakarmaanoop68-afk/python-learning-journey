# 🚀 Python Mini Project

Day 8 of my Python learning journey.

## Project: Student Management System

A beginner-friendly console project using:

- Variables
- Lists and dictionaries
- Functions
- Loops and conditions
- File handling
- JSON

## Features

- Add a student
- View all students
- Search a student
- Save student data to JSON
- Load student data from JSON
- Exit the program

## Goal

Combine the Python concepts learned so far into one practical project.
