# 🌐 Python API Data Explorer

Day 10 of my Python learning journey.

## Project: API Data Explorer

A beginner-friendly console project that fetches post data from a public REST API and works with the JSON response.

## Features

- Fetch post data from an API
- Search a post by ID
- Display post title and body
- Save selected posts to a local JSON file
- View saved posts
- Handle API errors and timeouts
- Use OOP to organize the API client

## API

This project uses JSONPlaceholder:
https://jsonplaceholder.typicode.com/

## Concepts Used

- Classes and objects
- Methods
- HTTP GET requests
- JSON
- Lists and dictionaries
- File handling
- Exception handling
- API error handling

## Run

Install the requests library:

```bash
pip install requests
```

Then run:

```bash
python api_explorer.py
```

## Learning Goal

Combine Python OOP, APIs, JSON, and file handling into one practical project.
